# Akram Cloud Workspace

هذه المساحة مخصصة لتجهيز بيئة تطوير سحابية لمشاريع أكرم، بحيث تتم أعمال التحرير والفحص والبناء في Codespaces بدل تحميل الهاتف عبء المعالجة.

## المبادئ

- إبقاء كل تطبيق مستقلًا داخل مجلد خاص به.
- عدم تعديل ملفات موقع Dragon الأصلية.
- عدم وضع كلمات مرور أو مفاتيح API أو بيانات Firebase السرية في المستودع.
- عدم اعتبار أي مشروع جاهزًا للبناء قبل استيراد مصدره وفحص إعداداته فعليًا.
- توثيق خطوات البناء ونتائج الاختبار لكل مشروع.

## المشاريع المخطط لاستيرادها

- AkramKeyboard
- AkramMediaPlayer
- AkramLauncher

## مراحل التجهيز

1. إعداد بيئة Codespaces وأدوات Java وAndroid SDK وGradle المناسبة.
2. استيراد مصدر كل مشروع كما هو، دون إعادة كتابة أو حذف.
3. فحص ملفات Gradle وManifest والاعتماديات.
4. تجربة البناء في البيئة السحابية وتوثيق الأخطاء.
5. تجهيز طريقة واضحة للوصول إلى ملفات APK الناتجة.

## الحالة الحالية

هذه وثيقة تأسيسية فقط. لم تُستورد مصادر التطبيقات بعد، ولم يُعلن نجاح أي بناء Android حتى الآن.
